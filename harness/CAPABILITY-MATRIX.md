# Native harness capability matrix

Reviewed 2026-10-05 against current official public documentation and this repository's implementation. This is a capability checklist, not a claim of Codex parity. Codex CLI, desktop, IDE and hosted products have different capabilities and availability; a documented product feature is not automatically an API entitlement.

**Native** means this harness owns the behavior. **Partial** identifies a narrower implementation. **Unavailable** means no implemented supported path. Test filenames identify reproducible evidence; offline transport, browser and desktop fixtures do not establish live provider/account/OS acceptance. Paths below are relative to `harness/`; runtime filenames are under `apps/runtime/src/`.

## Implementation milestones and acceptance

1. **Core checkpoint implemented:** independent native loop, bounded file tools, approvals, sessions, child analysis, official optional OpenAI login/native inference and separate search. Parent tracks exact pushed SHA and repository-wide CI in the checkpoint report.
2. **Browser/desktop checkpoint implemented and tested offline:** scoped native controllers/drivers, guarded routes, consent UX and offline regression fixtures. Inventory includes current source wording; native image/model transmission is not accepted from a local preview alone.
3. **Required live user actions:** configure stable OpenAI host identity, complete real login/consent in a reachable loopback environment, and explicitly authorize any actual provider or desktop execution. No credentials or login are generated by documentation/tests.
4. **Remaining engineering gaps:** live sandbox acceptance and unrestricted shell decisions, delete/rename/recursive file operations, Git push/PR/worktrees, full instruction/skill ecosystem semantics, reasoning-history preservation and production image/consent integration. These are not accepted by passing narrow fixtures.

See [acceptance evidence](CODEX-ACCEPTANCE.md), [provider contract](standalone-provider-auth.md) and [exact message inventory](Harness%20msgs%20to%20the%20models.md). Official repository source links above are moving public references, not a pinned imported runtime. No private Codex prompts, proprietary endpoints or undocumented client identities are required or reproduced.
